# 2026-02-17

## Objectives
- Initial hardware architecture definition.

- Define AXI Slave interface requirements for STM32 to Raspberry Pi communication.

- Initial power budget estimation.

## Work Completed
- Drafted the high-level block diagram for the PCB.

- Decided on the STM32F446 for the core logic due to its high-speed GPIO and built-in AXI/AHB bus capabilities.

- Defined the AXI Slave registers for the Raspberry Pi to command motor movements and capture triggers.

## Decisions Made
- Architecture: Use a 4-layer PCB to ensure signal integrity for the high-speed AXI interface and to provide a solid ground plane for motor noise isolation.

- Interface: Selected AXI over SPI for the Pi-to-STM32 link to allow for memory-mapped control of the digitization parameters.
