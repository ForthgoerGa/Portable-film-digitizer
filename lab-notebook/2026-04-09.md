## Objectives
- AXI Slave Interface Integration.

## Work Completed
- Configured the STM32 FMC (Flexible Memory Controller) to act as an AXI Slave.

- Developed the register map:

  - 0x00: Control Register (Bit 0: Start Scan, Bit 1: Reset).

  - 0x04: Motor A Steps.

  - 0x08: Motor B Steps.

  - 0x0C: LED Brightness (PWM).

## Code Entry (Snippet)
// AXI Register Write Handler
void AXI_Slave_Write(uint32_t addr, uint32_t data) {
    switch(addr) {
        case MOTOR_A_REG:
            step_motor(&motorA, data);
            break;
        case LED_PWM_REG:
            __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, data);
            break;
    }
}

Note: Logic adapted from STM32 HAL documentation with custom register mapping.
