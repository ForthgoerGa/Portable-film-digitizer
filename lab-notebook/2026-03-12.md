# 2026-03-12

## Objectives
- PCB Layout: Routing and signal integrity.

## Work Completed
- Routed the AXI bus traces using length matching to minimize skew.
- Implemented a "star ground" pattern to separate the analog sensor grounds from the noisy motor grounds.
- Verified footprints for the STM32F446 (LQFP64) and A4988 modules.

## Decisions Made
- Increased trace width for the motor power lines ($V_{BB}$) to 20 mils to support up to 2A peak current without significant voltage drop.
