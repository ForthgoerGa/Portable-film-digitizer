# Project Overview

## Summary
Portable film digitization device using an STM32 MCU, dual-mode illumination, and a cloud processing pipeline to deliver fast, social-media-ready images from 35mm, 120, and Instax formats.

## Objectives
- Provide a one-click digitization workflow.
- Achieve 4K output with acceptable dynamic range for common color negative film.
- Maintain portability and low power consumption.

## Scope
- Hardware platform (power, illumination, controller, sensor integration)
- Firmware control and capture pipeline
- Cloud processing prototype for image enhancement
- Lab notebook documentation for engineering decisions

## Key Risks
- Illumination uniformity and glare control
- End-to-end latency under variable network conditions
- Reliable negative inversion across different film stocks
